# Documentação do sistema Fecap Ágora

Esta pasta reúne a documentação principal do projeto mobile em React Native + Expo Router para o sistema Fecap Ágora.

## Visão geral

O aplicativo foi pensado como uma plataforma de conexões universitárias e oportunidades profissionais, com foco em:

- descoberta de vagas e empresas;
- match inteligente de oportunidades;
- rede de conexões entre estudantes, alumni e profissionais;
- assistente de IA para auxiliar na navegação;
- onboarding e autenticação.
